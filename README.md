# Superstore ETL Pipeline

## Overview
This project aims to build an end-to-end ETL pipeline using Python, MySQL, and Power BI.

## Technologies
- Python
- Pandas
- SQLAlchemy
- MySQL
- Power BI

## Project Workflow
1. Data exploration and cleaning with Python.
2. Database schema creation in MySQL.
3. Data extraction, transformation, and loading (ETL).
4. Data modeling and dashboard development in Power BI.
